## Code of conduct contact

Report conduct problems to the maintainers privately: open a private report to the maintainer via the repository's
Security tab or contact [@alexandrust88](https://github.com/alexandrust88) on GitHub. Reports are read only by
maintainers. If a report involves a maintainer, that maintainer is left out of handling it.

## Security contact

Security problems go through [SECURITY.md](SECURITY.md) (GitHub private vulnerability reporting), not through the
code of conduct contact.
