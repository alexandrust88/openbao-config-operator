# Changelog

All notable changes to this project are listed here. Versions follow [Semantic Versioning](https://semver.org).
The API is `v1alpha1`: fields can still change in a minor release under the
[deprecation policy](docs/reference/compatibility.md#deprecation-policy), and the release notes say so. Each version
links to its GitHub release, which lists the published artefacts, their digests and the merged pull requests.

Once the release-please GitHub App is configured, [release-please](https://github.com/googleapis/release-please)
writes new entries from the conventional-commit titles of merged pull requests. Do not edit released entries. The
process is in [docs/maintainers/release-process.md](docs/maintainers/release-process.md).

## Unreleased

First release: 1.0.0. Earlier pre-releases (0.1.x–0.5.0) were withdrawn.
